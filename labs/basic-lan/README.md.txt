# Lab 01 — Basic LAN + DHCP (Cisco Packet Tracer)

## Objective

Build a small local network where a router provides IP addresses automatically (DHCP) and two hosts communicate through a switch.

## Topology

Router → Switch → PC & Laptop

## Network Information

* Network: 192.168.0.0/24
* Gateway: 192.168.0.1
* DHCP Server: Router

## What I Configured

* Router interface IP addressing
* Enabled interface (no shutdown)
* DHCP pool configuration
* Default gateway distribution
* DNS distribution

## Verification

* PC and Laptop received IP automatically
* Successful ping to gateway
* Successful ping between devices

## Skills Demonstrated

* Basic network design
* DHCP configuration
* Interface configuration
* Network troubleshooting

## Tools Used

* Cisco Packet Tracer
